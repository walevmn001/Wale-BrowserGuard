# Danh sách module

Trạng thái: SPECIFIED.

Mỗi module ghi: tên, file, trách nhiệm, interface (`init`, `dispose`, `status`), dependency qua `ctx`, quyền ghi, feature flag, và trạng thái (SPECIFIED, IMPLEMENTED, TESTED, VERIFIED).

Danh sách đầy đủ hiện nằm ở `specs/001-yt-ad-shield/plan.md` mục 11.1 và 12.1. Khi code được viết, bảng này phải được cập nhật từ đó.
