# Prompt 10 — Khởi tạo repo GitHub (chạy MỘT lần ở đầu)

Chạy các bước sau và báo kết quả từng bước:
1. `git init` (nếu chưa có), đặt nhánh chính là `main`.
2. Kiểm tra `.gitignore` đã có. Commit toàn bộ tài liệu hiện có: "chore: add spec kit docs".
3. Hướng dẫn tôi tạo repo rỗng trên GitHub (private) và thêm remote `origin`. Chờ tôi xác nhận đã có URL.
4. `git push -u origin main`.
5. Xác nhận push thành công bằng `git status` và `git log origin/main -1`.
Không làm gì khác.
