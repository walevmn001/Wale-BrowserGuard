# Prompt 09 — Làm tiếp sau khi bị ngắt (lỗi server, hết dung lượng, phiên mới)

Đây là phiên làm việc mới. Hãy:
1. Đọc `PROGRESS.md`, `.specify/memory/constitution.md` và `tasks.md`.
2. Chạy `git status`, `git log --oneline -10`, và xác nhận nhánh hiện tại.
3. Chạy lint + test + build để xác định trạng thái thật của code.
4. Báo tôi: đang ở task nào, phần nào dở dang, có gì chưa commit/chưa push, test đang xanh hay đỏ.
5. KHÔNG viết code mới. Chờ tôi xác nhận task kế tiếp.
